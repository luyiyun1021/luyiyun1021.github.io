Block all reduce 学习 (sum, softmax)

发表于 2025-08-20 更新于 2025-08-22 分类于 cuda 阅读次数： 本文字数： 2.1k 阅读时长 ≈ 8 分钟

warp reduce几乎已经成为大部分reduce kernel的标准写法了，比如vLLM中，就是这种经典的写法。所以，先搞懂warp reduce（也就是搞懂各种warp functions的用法），再去写其他kernel，思路就会容易很多。需要注意的是，warp函数处理的是寄存器上的数据，也就是说，此时，没必要先加载数据到smem，再进行reduce，直接加载到寄存器即可。Warp Functions建议参考：jhang：CUDA编程入门之Warp-Level Primitives

block all reduce是在warp reduce的基础上进行的，reduce_smem这部分的共享内存申请无法避免，这是用来同步每个warp之间得到局部结果。注意，最后，还需要atomicAdd做一个block级别的原子操作，以得到全局的和。float4向量化优化访存，可以减缓WarpScheduler发送指令的压力。

safe softmax per token

算法概述

Safe Softmax 是 Softmax 的数值稳定版本，通过减去最大值来避免指数运算的数值溢出问题。

标准 Softmax 公式：

softmax(x_i) = e^x_i / Σ(e^x_j)

Safe Softmax 公式：

softmax(x_i) = e^(x_i - max(x)) / Σ(e^(x_j - max(x)))

CUDA代码

一共s*h个block, 每个block处理h个元素, 内部对于x进行block all reduce max计算, 再对e^x - max_val进行block all reduce sum计算, 最后exp_val / exp_sum

两个MD值合并的数学推导

假设有两个状态：

  • MD1: (m1, d1) 代表 max=m1, sum_exp=d1

  • MD2: (m2, d2) 代表 max=m2, sum_exp=d2

合并后：

  • m_new = max(m1, m2)

  • d_new = d1 * exp(m1 - m_new) + d2 * exp(m2 - m_new)

MD值合并的数学等价性证明

问题描述

我们需要证明：将两个独立计算的softmax状态合并，与直接对所有元素计算softmax是数学等价的。

符号定义

假设我们有两组数据：

  • 集合A: {a₁, a₂, ..., aₙ}，其对应的MD状态为 (m1, d1)

  • 集合B: {b₁, b₂, ..., bₖ},，其对应的MD状态为 (m2, d2)

其中：

  • m1 = max(a₁, a₂, ..., aₙ)

  • d1 = Σᵢ exp(aᵢ - m1) = exp(a₁-m1) + exp(a₂-m1) + ... + exp(aₙ-m1)

  • m2 = max(b₁, b₂, ..., bₖ)

  • d2 = Σⱼ exp(bⱼ - m2) = exp(b₁-m2) + exp(b₂-m2) + ... + exp(bₖ-m2)

数学直觉理解

这个等价性的核心在于指数函数的性质：

exp(a - M) = exp(a - m + m - M) = exp(a - m) * exp(m - M)

当我们改变参考点（从局部最大值m到全局最大值M）时，需要用 exp(m - M) 因子来重新调整所有之前计算的指数和。

算法优势对比

传统Safe Softmax vs Online Safe Softmax

特性 传统方式 Online方式
遍历次数 2次 1次
内存访问 2×N 1×N
寄存器使用 较少 较多
数值稳定性 ✓ ✓
计算复杂度 O(N) O(N)

性能优势

  1. 减少内存访问：从 2N 降低到 N

  2. 更好的缓存局部性：一次遍历，数据在缓存中热度更高

  3. 减少全局内存延迟：特别在大序列场景下优势明显
