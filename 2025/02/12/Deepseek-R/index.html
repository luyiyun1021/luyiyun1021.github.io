Deepseek-R

1.背景

2025年01月20日，DeepSeek 发布了两个参数为 660B 的 DeepSeek-R1-Zero 和 DeepSeek-R1，并选择开源了模型权重，同时允许用户使用 R1 来训练其他模型。

  • 开源 DeepSeek-R1 推理大模型，与 o1 性能相近。‍‍

  • 开源 DeepSeek-R1-Zero，预训练模型直接 RL，不走 SFT。

  • 开源用 R1 数据蒸馏的 Qwen、Llama 系列小模型，蒸馏模型超过 o1-mini 和 QWQ。

模型开源的同时，技术报告也同步放出： DeepSeek-R1: Incentivizing Reasoning Capability in LLMs viaReinforcement Learning

在技术层面，R1 在后训练阶段大规模使用了强化学习（RL）技术，在仅用非常少标注数据的情况下，极大提升了模型推理能力。下图为 R1 与 o1-1217、o1-mini、自家 DeepSeek-V3 在多个数据集上的性能比较，可以看到，R1 与 o1-1217 不相上下、互有胜负。

另外，使用 DeepSeek-R1 整理的 80 万个样本对 Qwen 和 Llama 等开源模型进行了微调，蒸馏出了六个小模型，参数从小到大分别为 1.5B、7B、8B、14B、32B 以及 70B。这六个模型同样完全开源，旨在回馈开源社区，推动「Open AI」的边界。

模型下载地址：https://huggingface.co/deepseek-ai?continueFlag=f18057c998f54575cb0608a591c993fb

性能方面，蒸馏后的 R1 32B 和 70B 版本远远超过了 GPT-4o、Claude 3.5 Sonnet 和 QwQ-32B，并逼近 o1-mini。

至于很多开发者关心的 DeepSeek-R1 API 价格，可以说是一如既往地给力。

DeepSeek-R1 API 服务的定价为每百万输入 tokens 1 元（缓存命中）/ 4 元（缓存未命中），每百万输出 tokens 16 元。

与 o1 的 API 定价比起来（每百万输入 tokens 15 美元、每百万输出 tokens 60 美元），DeepSeek 具有极高的性价比。

2.DeepSeek为什么火

一个是证明了一众小模型（低至1.5B）也可以实现深度推理，这也就意味着没有显卡储备的普通的学生也可以在自己电脑上做实验。

其次，对于企业而言，价格低到几乎可以忽略不计的使用成本，完全可以打消投入产出比的顾虑。

  • DeepSeek 同步上线的 R1 模型的 API，价格只有 o1 模型的 5%。

第三，推理模型的开源，代码流程公开透明，使得不管是普通开发者还是企业部署，都有了灵活可定制自身推理模型的潜力。

第四，DeepSeek-R1的爆火，已经冲击了全球的算力的逻辑。

“大型科技公司在AI上投入了大量资金，几乎达到了一国政府预算的规模，但一直存在一个问题，即产生的回报能否与其投资规模相匹配。“

据报道，DeepSeek实验室只花了560万美元来建造DeepSeek V3。相比之下，OpenAI每年花费50亿美元，而谷歌预计2024年的资本支出将飙升至超过500亿美元。还有微软，仅投资OpenAI就花费了超过130亿美元。

所以总结来看，R1的爆火在于解决了以o1为代表的大模型现存的几大问题：太贵、部署门槛高、不透明、灵活性差（不可定制）。R1 解决了所有问题。

论文

1. 研究背景与动机

近年来，大型语言模型（LLMs）在人工智能领域快速发展，逐渐接近人工通用智能（AGI）。

然而，尽管模型规模不断扩大，其推理能力仍面临挑战。

  • 推理能力：指模型在解决复杂问题时，能够通过逻辑思考、多步骤分析等方式得出正确答案的能力。

  • 数学问题、编程任务和科学推理等领域

以往的研究通常依赖于大量的监督数据来提升模型的推理能力，但这种方法存在局限性：

  • 收集和标注监督数据需要大量的人力和时间成本；

  • 监督学习可能无法充分发挥模型的自我进化能力。

2. 研究方法

2.1 DeepSeek-R1-Zero：基于强化学习的推理能力提升

DeepSeek-R1-Zero是通过强化学习直接对基础模型进行训练，而无需监督微调（SFT）作为预处理步骤。

作者采用了GRPO算法，这是一种高效的强化学习算法，通过比较同一问题的不同回答来优化模型的策略。

  • **出处：**DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models中提出，主要目的是降低RL的训练算力消耗和简化主流RL算法例如PPO。

  • GRPO算法的核心思想是通过采样一组输出，计算这些输出的奖励，并根据奖励的相对值来更新模型参数。

  • 不需要Value Model的训练。

  • **直观理解：**模型奖励好于群体平均的策略，打压差于群体平均的策略。

2.1.2 奖励建模

为了训练DeepSeek-R1-Zero，作者设计了一个基于规则的奖励系统，主要包括准确性和格式两个方面的奖励。

  • 准确率奖励：准确率奖励模型评估响应是否正确。例如，

    • 在具有确定性结果的数学问题中，模型需要以指定的格式提供最终答案，从而能够通过基于规则的验证来可靠地确认正确性。

    • 对于 LeetCode 问题，可以使用编译器根据预定义的测试用例生成反馈。

  • 格式奖励: 要求模型将思考过程放在特定的标签（如<think>和</think>）之间

在没有大量带「过程标签」（step-by-step annotation）的数据支撑下，模型如何知道自己的推理过程是否正确？

  • 这里主要通过「结果判定」的方式：对于数学题、编程题等有客观正确答案的任务，可以把最终答案与标准结果对比给出奖励。

2.1.3 训练模板

作者设计了一个简单的模板来指导模型的输出格式：模型首先需要生成一个推理过程，然后给出最终答案。

这种模板设计避免了对内容的具体限制，以便观察模型在强化学习过程中的自然演变。

2.1.4 性能表现与自我进化

DeepSeek-R1-Zero在训练过程中表现出显著的性能提升。

  • 在AIME 2024基准测试中，模型的Pass@1分数从15.6%提升到71.0%，并且通过多数投票进一步提升到86.7%，与OpenAI的o1-0912模型相当。

  • 此外，模型在训练过程中自然地发展出了复杂的推理行为，如反思和探索多种解题方法。

不过 DeepSeek-R1-Zero 仍然存在一些局限性，如回答的可读性差、语言混杂等问题。

强化学习可以不依赖人类反馈，纯 RL 也能训练出最强的 Reasoning 模型。

一些感受

想要超越人类，必须让模型摆脱人类经验、好恶判断的限制，只有这样才能让模型 真正超越人类的束缚。

AI 终于除掉了人类反馈的枷锁。DeepSeek R1-Zero 展示了如何使用几乎不使用人类反馈来提升模型性能的方法。很多人曾说“人工智能，有多少人工就有多少智能”，这个观点可能不再正确了。如果模型能根据直角三角形推导出勾股定理，我们有理由相信它终有一天，能推导出现有数学家尚未发现的定理。

2.2 DeepSeek-R1：结合冷启动数据的强化学习

整体流程：

DeepSeek-R1 使用了冷启动 + 多阶段训练的方式：

  • 阶段1：使用少量高质量的 CoT 数据进行冷启动，预热模型。

  • 阶段2：进行面向推理的强化学习，提升模型在推理任务上的性能。

  • 阶段3：使用拒绝采样和监督微调，进一步提升模型的综合能力。

  • 阶段4：再次进行强化学习，使模型在所有场景下都表现良好。

阶段1: 冷启动

冷启动阶段使用少量高质量的 CoT 数据对基础模型进行微调，作为 RL 训练的初始起点。侧重点是让模型掌握基本的 CoT 推理能力，并使模型的输出更具可读性。

数据收集：

为了获取这些数据，deepseek 探索了几种策略：

  • 利用长思维回答作为 few-shot 示例

  • 直接提示模型生成包含反思和验证步骤的详细答案

  • 收集 DeepSeek-R1-Zero 的输出并通过人工标注者进行细化

最终收集了数千条冷启动数据，用以微调 DeepSeek-V3-Base 作为 RL 训练的起点。DeepSeek-R1 创建的冷启动数据采用了一种可读模式，明确将输出格式定义为：|special_token|<reasoning_process>|special_token|<summary>。

训练重点：

  • 可读性：冷启动数据使用更易于理解的格式，输出内容更适合人类阅读，避免了 DeepSeek-R1-Zero 输出的语言混合、格式混乱等问题。

  • 潜在性能：通过精心设计冷启动数据的模式，可以引导模型产生更好的推理能力。

  • 稳定训练：使用 SFT 数据作为起始点，可以避免 RL 训练早期阶段的不稳定问题。

阶段成果：

  • 强化学习的稳固基础 ，减少后续训练中的不稳定性。

阶段2: 推理导向的强化学习

在冷启动模型的基础上进行 RL 训练，侧重点是提升模型在推理任务上的性能。

在该阶段，引入 GRPO 以提升模型在 数学、编程和结构化问题求解 方面的推理能力。

  • 奖励函数: 推理任务的准确性 + 语言一致性奖励

  • 规则奖励（Rule-Based Rewards） ：

    • 强调 准确性 （如解决编程问题、验证数学结果）。

    • 设定 格式化规则 ，确保清晰表达（如用特定标签 <reasoning> 包围思考过程）。

  • 新奖励信号（New Reward Signal） ：

    • “语言一致性”奖励 ，鼓励模型在整个输出过程中保持相同语言风格。根据思维链（CoT）中目标语言单词的比例来计算，以减少推理过程中的语言混合问题。

  • 阶段成果：

    • 推理能力显著提升 ，在 AIME 2024 竞赛中 pass@1 分数提升至 71.0% 。

阶段3: 拒绝采样和 SFT

与初期主要关注推理能力的冷启动数据不同，这一阶段加入了其他领域的数据，旨在增强模型在写作、角色扮演以及其他通用任务上的表现。

当 RL 训练接近收敛时，使用中间的 checkpoint 来采样监督微调（SFT）数据。具体步骤如下：

  • 对于推理数据，构建推理 prompt，并从上述 RL 训练的 checkpoint 中进行拒绝采样，以生成推理轨迹。

    • 在之前的阶段，仅使用了基于规则的奖励来评估数据。然而，在这个阶段，通过添加其他数据来丰富数据集，其中部分数据使用了生成奖励模型，通过将真实值和模型预测输入 DeepSeek-V3 进行判断。

    • 为了提升数据质量，过滤掉混合语言、长段落的思维链。

    • 对于每个提示，采样多个响应，并仅保留正确的响应。最终，收集了大约60万个与推理相关的训练样本。

  • 对于非推理数据，如写作、问答、翻译等任务，使用 DeepSeek-V3 SFT 数据集的一部分。

    • 对于简单的 query，如“你好”，不使用思维链作为回答。

    • 经过筛选和整理，最终收集了大约20万个与推理无关的训练样本。

最终，使用大约80万个样本（60w推理+20w通用）对 DeepSeek-v3-Base 模型进行了两轮的 SFT。

  • 阶段成果：

    • 模型在更广泛任务上的通用性和连贯性增强 。

阶段4: 所有场景下的强化学习

为了进一步使模型与人类偏好保持一致，这里还要实施第二阶段强化学习，旨在提高模型的有用性和无害性，同时完善其推理能力。

具体来说，研究人员使用奖励信号和各种提示分布的组合来训练模型:

  • 对于推理数据，遵循 DeepSeek-R1-Zero 中概述的方法，该方法利用基于规则的奖励来指导数学、代码和逻辑推理领域的学习过程；

  • 对于一般数据，则采用奖励模型来捕捉复杂而微妙的场景中的人类偏好。

多阶段训练的核心见解

早期 SFT 稳定 RL 训练：

  • 在强化学习前进行 监督微调 可 减少训练不稳定性 ，加速收敛。

规则奖励机制高效：

  • 简单、针对性的奖励 （如准确性、格式要求）往往 比复杂奖励模型更有效 。

拒绝采样提升模型适应性：

  • 通过 拒绝采样生成合成数据 ，可以 增强模型的泛化能力 ，适应不同任务。

通过 在 SFT 和 RL 之间 交替训练 ，DeepSeek 团队成功 解决了强化学习的冷启动问题及任务过拟合问题 ，使 DeepSeek R1 在推理和更广泛的应用场景中都能表现卓越。

2.3 DeepSeek-R1知识蒸馏：将推理能力赋予小型模型

蒸馏小模型

为了获得更高效的小模型，并使其具有 DeekSeek-R1 的推理能力，直接对 Qwen 和 Llama 等开源模型进行了微调，使用的是上面 SFT DeepSeek-R1 的80万数据。研究结果表明，这种直接蒸馏方法显著提高了小模型的推理能力。

  • 在这里使用的基座模型是 Qwen2.5-Math-1.5B、Qwen2.5-Math-7B、Qwen2.5-14B、Qwen2.5-32B、Llama-3.1-8B 和 Llama-3.3-70B-Instruct。

为什么在蒸馏到小模型时，直接用 RL 在小模型上训练不如先做大模型再蒸馏？

  • 大模型在 RL 阶段可能出现许多高阶推理模式。而小模型因为容量和表示能力有限，很难在无监督或纯 RL 情境下学到相似水平的推理模式。

  • 蒸馏可将「大模型的推理轨迹」直接转移给小模型，小模型只需要模仿大模型相对完备的推理流程，可以在较小训练/推理开销下取得远胜于自身独立强化学习的效果。

在蒸馏模型的实现中，仅采用了 SFT 阶段，而未包含 RL 阶段，尽管 RL 的加入能显著提升模型性能。

  • 核心目的在于展示蒸馏技术的有效性。

3. 实验结果

3.1 DeepSeek-R1-Zero评估

3.1.1 推理任务性能

  • AIME 2024：DeepSeek-R1-Zero 在 AIME 2024 基准测试中的 Pass@1 分数从 15.6% 提升到 71.0%，通过多数投票进一步提升到 86.7%，与 OpenAI-o1-0912 的性能相当（见表 2 和图 2）。

  • MATH-500：DeepSeek-R1-Zero 在 MATH-500 任务中的 Pass@1 分数达到 86.7%，表现非常出色（见表 2）。

  • Codeforces：DeepSeek-R1-Zero 在 Codeforces 编程任务中达到了 1444 的 Elo 评分，超过了 50.0% 的人类参赛者（见表 2）。

  • GPQA Diamond：在 GPQA Diamond 任务中，DeepSeek-R1-Zero 的 Pass@1 分数为 95.9%，表现出色（见表 2）。

3.1.2 推理能力的自我进化

推理过程的复杂性：DeepSeek-R1-Zero 在训练过程中自然地发展出了复杂的推理行为，例如 反思（reflection） 和 重新评估（reevaluation）。模型会通过增加思考时间（生成更多的推理 token）来解决更复杂的推理任务。

  • “Aha Moment”：在训练过程中，DeepSeek-R1-Zero 展示了一些有趣的“顿悟时刻”，例如在解决数学问题时，模型会重新评估其初始方法，并尝试不同的解题策略

3.1.3 语言和可读性问题

尽管 DeepSeek-R1-Zero 在推理任务上表现出色，但它在语言表达和可读性方面存在一些问题：

  • 语言混合

  • 格式问题

3.2 DeepSeek-R1评估

DeepSeek-R1在多个推理任务上取得了与OpenAI的o1-1217相当甚至更好的性能。例如:

  • 在AIME 2024基准测试中，DeepSeek-R1的Pass@1分数达到了79.8%，略高于OpenAI-o1-1217。

  • 在MATH-500任务中，DeepSeek-R1的Pass@1分数达到了97.3%，与OpenAI-o1-1217相当。

  • DeepSeek-R1在编程任务（如Codeforces）上也表现出色，其Elo评分达到了2029，超过了96.3%的人类参赛者。

3.3 DeepSeek-R1蒸馏模型评估

经过DeepSeek-R1蒸馏的小型模型在推理任务上表现出色。例如:

  • DeepSeek-R1-Distill-Qwen-7B在AIME 2024任务上的Pass@1分数达到了55.5%，超过了QwQ-32B-Preview。

  • DeepSeek-R1-Distill-Qwen-32B在AIME 2024任务上的Pass@1分数达到了72.6%，在MATH-500任务上的Pass@1分数达到了94.3%，显著优于其他开源模型。

4. 讨论

4.1 知识蒸馏与强化学习

论文指出，尽管强化学习可以显著提升模型的推理能力，但直接在小型模型上进行大规模强化学习可能需要巨大的计算资源，并且效果不如知识蒸馏。知识蒸馏是一种更经济且有效的方法，可以将大型模型的推理能力传递给小型模型。

4.2 未成功的尝试

为什么 PRM 和 MCTS 没有成功？

论文中提到，基于过程奖励模型（PRM）和蒙特卡洛树搜索（MCTS）并不适合 LLM 的推理。

PRM 的挑战

  • 难以定义通用的、细粒度的推理步骤。

  • 难以准确判断中间步骤的正确性，且自动标注方法效果不佳，人工标注又难以扩展。

  • 模型化的 PRM 容易导致奖励黑客（Agent 利用奖励函数或环境中的漏洞来获取高奖励，而并未真正学习到预期行为），并且会增加额外的训练成本。

MCTS 的挑战

  • LLM 的 token 生成搜索空间巨大，远远超出棋类游戏，容易陷入局部最优解。

  • 价值模型的训练非常困难，导致难以迭代提升。

4.3 结论、限制与未来工作

DeepSeek-R1在一些任务上（如函数调用、多轮对话等）的表现仍不如DeepSeek-V3。

模型在处理非中文和英文查询时可能会出现语言混合问题。

未来的工作将致力于解决这些问题，并进一步提升模型的通用性和推理能力。

4.4 R1-Zero启用了新的训练范式：只使用RL，省略SFT

Q：为什么省略SFT是好事？

A：因为找到大量符合CoT模版的高质量数据并不容易。以DeepSeek-Math-7B为例，用到了776K条样本做SFT。而DeepSeek-R1几乎不用这样的样本（用到了几千条做冷起）。

Q：更器重RL的好处？

A：RL面对复杂问题具有很大的潜力，具有self-evolution的能力，也许可以激发出pre-train里的高质量回答。

5. 小结与思考

小结：这篇论文通过详细的实验和分析，展示了如何通过强化学习提升LLMs的推理能力，并通过知识蒸馏将这些能力传递给小型模型。这一研究为未来开发更智能、更高效的LLMs提供了重要的参考和启示。
